# website-wireframes
This project is an exercise in designing and building a React app with wireframe layouts in &lt; 24 hours. This website is a potential mortgage and realty website. It uses React, Typescript, Tailwind, and my personal NPM component library (https://github.com/DG-Product-Design/component-library)

To run the app:
1. Clone project from github: (https://github.com/DG-Product-Design/website-wireframes)
1. Navigate to project folder in your terminal and install node_modules dependencies: `npm i` or `yarn install`
1. Once the dependencies are done installing, run: `npm run start` or `yarn start`
